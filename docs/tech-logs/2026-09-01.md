## 本轮目标与基线判断

仓库从 GitHub 克隆到 `D:\AI\Codex\Zaqizaba\shuati platform`。原实现已经有注册、题库、前端编辑器和本地判题纵向链路，但运行态使用内存仓储，重启会丢失账号、题目和提交；`LocalCppRunner` 直接在宿主机运行不可信代码，不能暴露公网；项目也没有 HTTPS、免费域名或服务托管配置。

“能线上做题”的最低安全边界应同时包含：业务状态可恢复、用户代码不在宿主机直接执行、后端只监听回环地址并由反向代理提供 HTTPS。只把原端口映射到公网不算完成。

## 可复用实现判断

个人和小规模试用先使用原子状态文件，而不是在本轮仓促接入半套 MySQL。`users.state`、`problems.state`、`submissions.state` 位于 `storage.state_dir`，写入时先生成 `.tmp` 再替换正式文件。字段中的任意 UTF-8 文本使用十六进制编码，避免换行、制表符和引号破坏行协议。该方案只适用于单进程、单机实例；多实例扩容必须迁移到数据库。

公网配置强制 `app.environment: production` 与 `judge.runner: docker` 组合，并拒绝默认或占位管理员密码。Docker runner 使用固定命令模板，不拼接用户源码到 shell，容器设置 `--network none`、CPU/内存/pids 限制、只读根文件系统、临时 `/tmp`、`no-new-privileges`、删除 capabilities，并用 `RLIMIT_FSIZE` 限制输出文件。宿主进程仅挂载当前提交的临时目录。

同步 HTTP 判题仍使用“创建后按指定 submission id 领取”，不能调用通用 `claimNextPending`。后者在并发或恢复队列存在旧任务时可能领取别人的提交，导致当前提交被错误完成而旧任务停在 Running。本轮新增 `claimPendingById` 并以回归测试覆盖。

免费域名选用 DuckDNS 子域名，HTTPS 使用 Nginx + Certbot。部署入口是 `deploy/install_ubuntu.sh`，生产配置在 `/etc/shuati/app.yaml`，业务状态在 `/var/lib/shuati`，日志在 `/var/log/shuati`，服务单元是 `deploy/shuati.service`。部署脚本需要公网 Ubuntu 主机、DuckDNS 名称/token 和管理员密码；这些外部资源不能写进仓库。

## 本机临时公网体验（Windows + WSL）

由于当前没有公网 Linux 主机，本轮使用 WSL2 在 Windows 本机运行单进程 demo：项目位于 `D:\\AI\\Codex\\Zaqizaba\\shuati platform`，WSL Debian 数据目录位于 `D:\\AI\\Codex\\wsl\\debian`，下载与安装缓存位于 `D:\\AI\\Codex\\setup-cache`。WSL 官方安装器的系统组件仍由 Windows 安装到系统位置；可控的安装包、发行版虚拟磁盘和项目运行数据均未放到 C 盘。C 盘仅保留早期失败下载产生的旧 MSI 缓存副本，因 EFS/系统策略不能强删。

WSL 默认下载源返回 403，因此改用 D 盘缓存的微软签名 WSL MSI 和 Debian Appx/rootfs。Docker Hub 在本机超时，先把 Debian rootfs 导入为本地 `shuati-debian-base:bullseye`，再通过 `--build-arg BASE_IMAGE=shuati-debian-base:bullseye` 构建 `shuati-cpp-judge:latest`；生产 Dockerfile 默认基础镜像仍是 `ubuntu:24.04`。Debian 11 的链接器需要显式 `Threads::Threads`，因此 CMake 增加 `find_package(Threads REQUIRED)` 并链接该目标。

本机配置使用被忽略的 `config/app.local.yaml`，端口为 `18080`，状态、题目、提交源、日志和判题临时目录均在 `runtime-demo`（D 盘路径）。真实 API smoke 已通过，包含注册、登录、建题、上传测试点和 Docker C++ Accepted。

临时公网入口使用 D 盘缓存的 Tailscale 1.102.3 Linux amd64 二进制，状态文件在 `runtime-demo/tailscale`；Unix socket 放在 WSL 的 `/run/shuati-tailscaled.sock`，这是运行时套接字而非持久数据。当前 Funnel 地址为 `https://laptop-arse7fsr.tail1fcf74.ts.net/`，外网 `/api/health` 已返回 200。该地址依赖本机开机、WSL、`dockerd`、`tailscaled` 和 `shuati_server` 持续运行；停用可执行 `tailscale funnel --https=443 off`，再停止对应终端会话并执行 `wsl --shutdown`。

## C17 题库扩展

为现有在线题库增加了最大公约数、数组逆序、统计正负数、回文字符串、数字各位和 5 道 C 语言入门题，每题包含公开样例和多组隐藏测试点。内置种子按标题幂等补齐，因此已有只包含 A+B 的运行目录重启后也会自动得到新增题目，不会重复创建。

提交接口现在接受 `language: "c"` 和 `language: "cpp"`。C17 使用 `gcc -std=c17`，C++ 使用 `g++ -std=c++17`；Docker 判题镜像同时安装 gcc/g++，前端题目页提供语言选择，并依据 C 语言标签预选 C17。C17 最大公约数提交已通过公网接口验证为 Accepted，原有 C++ API smoke 也保持 `API_SMOKE_OK`。
